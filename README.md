## Want to double-check a download? (optional)

Windows and macOS installers are code-signed and notarized, so your operating
system verifies them automatically when you run them.

If you'd like to verify a file yourself, every release includes a
`SHA256SUMS.txt` (linked under each download table):

```bash
sha256sum --check --ignore-missing SHA256SUMS.txt
```

Linux packages (`.deb` / `.rpm`) additionally carry GPG signatures. Import the
Linux signing key (also linked under each table) and verify:

```bash
gpg --import orchestris-linux-release-key.asc
gpg --verify orchestris<...>.deb.asc orchestris<...>.deb
```
